How to play

  1. Choose a difficulty and start the sprint.
  2. Read each Mati heritage statement and choose True or False before time runs out.
  3. Answer quickly to earn points. The sprint ends when all questions are answered.

Each correct answer earns points. Faster rounds have shorter time limits and give more points for each correct answer.
